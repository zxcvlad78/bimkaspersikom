# BeamNG-Style Vehicle Physics Plugin

Плагин для Unity с реалистичной симуляцией автомобильной физики и мультиплеером.

## Возможности

- Деформируемые кузовные детали с реалистичным повреждением
- Реалистичная подвеска (независимая, McPherson, двухрычажная)
- Физика двигателя с термодинамикой
- Трансмиссия (механика, автомат, вариатор)
- Топливная система
- Электрическая система
- Охлаждение и перегрев
- Сетевая синхронизация через Mirror/Netcode

## Структура

- Core/ - ядро физики
- Components/ - компоненты автомобиля
- Networking/ - мультиплеер
- Editor/ - инструменты редактора
- Examples/ - примеры

## Требования

- Unity 2021.3+
- Mirror или Unity Netcode for GameObjects
