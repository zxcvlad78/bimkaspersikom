# Realistic Vehicle Physics (Godot 4.7 + Rust / GDExtension)

Симулятор автомобиля уровня BeamNG: **полная физика** (рейкаст-подвеска, шины по Magic Formula,
двигатель с кривой момента, КПП, дифференциалы, ABS/TCS/ESC) и **полная кастомизация** —
машина собирается из любых деталей каталога в «гараже».

Ядро написано на **Rust** (workspace из двух крейтов):

* `vehicle-core` — чистая физика на `glam` (тестируется без Godot),
* `godot-vehicle` — GDExtension-мост к Godot 4.7 (`api-4-7`).

## Что сделано в этой версии

### Исправленные баги физики (машина реально поехала)

| Проблема | Причина | Исправление |
|---|---|---|
| Машина стояла на месте | Коллайдер кузова упирался в землю → подвеска не сжималась → 0 Н нагрузки → буксование → TCS срезал газ до 5 % | Плагин сам создаёт коллайдер кузова **над колёсами** (`VbvCarBody.ensure_collider`) |
| Крен набок, одна сторона отрывалась | Стабилизатор поперечной устойчивости был **с обратным знаком** — не гасил крен, а раскачивал машину | Знак инвертирован в `vehicle-core/src/vehicle.rs` |
| Нагрузки «прыгали» на ±4 кН | Демпферы (3600/5200 Н·с/м) давали численную неустойчивость на шаге 1/60 с (режим «прыжка колеса» ~17 Гц) | Демпферы 2200/3000 + скорость подвески считается **из кинематики кузова**, а не из разности длин между кадрами |
| TCS душил двигатель | Следствие отсутствия нагрузки на колёса | Устранено вместе с коллайдером |
| **Не было звука, мотор не заводился** | Зажигание было сделано как momentary-кнопка (`pressed`), а не как тумблер: игрок отпускал F — зажигание выключалось, мотор глох | Зажигание — переключатель (`ignition_on`, `#[export]`), по умолчанию включено |
| Кузов «отрывался» от колёс | Модуль визуализации добавлялся в корень сцены, а не в машину: колёса брали мировые трансформы, кузов оставался на месте | `CarVisual` добавляется как дочерний узел машины |

Результат замеров (`demo/physics_test.tscn`): **0 → 110.8 км/ч за 9 с**, крен 0.4°,
нагрузки на колёсах симметричные (4348 / 4345 / 5193 / 5190 Н), ошибок нет.

### Новое в демо

* **Графика** (`demo/car_visual.gd`) — кузов из примитивов: нижний кузов, поясная линия, салон со
  стеклом, крыша, клин капота и багажника, бампера, зеркала, выхлопная труба, фары со
  `SpotLight3D`, задние фары, **4 колеса с дисками**, которые вращаются и поворачиваются по
  телеметрии подвески.
* **Звук** (`demo/engine_audio.gd`) — процедурный синтез в реальном времени, без аудиофайлов:
  вспышки сгорания по цилиндрам (частота = RPM/60 × цилиндры/2), резонанс выпуска
  (biquad band-pass), формант выхлопной трубы, свист турбины и шипение по бусту,
  сброс давления (blow-off) при сбросе газа, визг редуктора, шорканье шин по slip,
  шум дороги и ветра, мягкий лимитер.
* **Приборы** (`demo/hud.gd`) — тахометр с красной зоной и стрелкой, крупная скорость и
  передача, мощность, буст, температуры воды/масла, топливо, индикатор перегрузки,
  индикаторы двигателя/ESC/ручника, FPS и подсказка по управлению.
* **Гараж** (`demo/garage.gd`) — «симулятор автомеханика»: 6 категорий деталей (двигатель, КПП, шины,
  дифференциал, подвеска, привод), цены/массы/характеристики, кнопки «Применить» / «Сбросить»,
  список проблем совместимости сборки, итоговая масса/цена/мощность. Пока меню открыто,
  управление машиной приостанавливается.

## Управление

| Клавиша | Действие |
|---|---|
| **W / S** | Газ / тормоз |
| **A / D** | Руль |
| **Shift** | Ручной тормоз |
| **Q** | Сцепление (выжать) |
| **E / R** | Передача вверх / вниз |
| **F** | Зажигание (тумблер вкл/выкл) |
| **Space** | Стартер |
| **G** | Открыть/закрыть гараж |
| **TAB / ESC** | Гараж (дублирует G) / закрыть меню |

## Архитектура

```
rust/vehicle-core          чистая физика (glam, без Godot) — модульные тесты
  vehicle.rs               RigidBody-подобная модель: подвеска, колёса, шины, аэродинамика
  powertrain/              engine, clutch, transmission, differential, brakes
  tire.rs                  Magic Formula + relaxation length + износ
  suspension.rs            пружина, амортизатор, отбойник, стабилизатор
  catalog.rs               пресеты деталей и готовые сборки
  assembly.rs              сборка деталей -> VehicleConfig (с валидацией)

rust/godot-vehicle         GDExtension-мост
  vehicle_body.rs          VbvCarBody (RigidBody3D): считает силы в ядре и применяет их
  assembly.rs              CarAssemblyResource + VehicleCatalog
  parts.rs                 ресурсы деталей (Engine/Gearbox/Tire/Chassis/...)
```

Поток сил: ядро считает **мировую силу и момент** → `VbvCarBody` применяет их к `RigidBody3D`
(`apply_central_force` / `apply_torque`), столкновения и общая динамика — штатный движок Godot.

Координаты: как в Godot — **Y вверх, −Z вперёд**, начало кузова на уровне земли,
по центру колёсной базы.

## Сборка и тесты

```bash
cd rust
cargo build -p godot-vehicle   # -> rust/target/debug/vehicle_physics.dll
cargo test -p vehicle-core     # 16 юнит-тестов ядра
cargo build -p godot-vehicle --release   # релизная сборка для продакшена
```

Готовую dll копируем в `addons/vehicle_physics/bin/`.

---

## Установка в Godot 4.7

1. Скопировать `addons/vehicle_physics/bin/vehicle_physics.dll` в проект.
2. `addons/vehicle_physics/vehicle_physics.gdextension` уже ссылается на dll.
3. В `Project Settings → Extensions` подключить `vehicle_physics`.

## API класса `VbvCarBody`

* `rebuild()` — пересобрать машину из `assembly`;
* `get_speed()`, `get_speed_kmh()`, `get_rpm()`, `get_gear()`, `is_engine_running()`;
* `get_telemetry() -> Dictionary` — скорость, G, yaw rate, колёса на земле, slip, understeer;
* `get_engine_state() -> Dictionary` — RPM, момент, кВт, boost, AFR, температуры, топливо,
  сцепление, гидротрансформатор, TCS, fuel cut, knock, износ;
* `get_wheel_info() -> Array` — по каждому колесу: контакт, нагрузка, slip, угол руля, вращение;
* `get_wheel_transforms() -> Array` — мировые трансформации колёс `[FL, FR, RL, RR]` (для визуала);
* `get_visual_spec() -> Dictionary` — габариты кузова, радиус/ширина шины, масса, цилиндры, redline;
* `get_suspension_debug() -> Array` — длина/сжатие подвески, скорость, нагрузка по колесам;
* `get_validation() -> Array[String]` — проблемы сборки;
* `set_controls(throttle, brake, steer, handbrake)` — ручное управление (для ИИ и тестов).

Сигналы: `engine_state_changed(running)`, `gear_changed(gear)`.
